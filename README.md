# 🌷 오늘의 꽃 카드뽑기

라이브 방송용 꽃 카드뽑기. 브라우저만 있으면 됩니다.

**바로 열기 → https://hgim94984-droid.github.io/flower-card-draw/**

## 어떻게 진행되나

1. **오늘의 카드 뽑기** — 234장 중 랜덤 8장이 그림면으로 펼쳐집니다. 카드 아래에 꽃 이름과 번호가 함께 나옵니다.
2. **번호 부르면 뒤집기** — 시청자가 부른 번호를 누르면 그 카드가 뒤집힙니다. 한 번 더 누르면 되돌아옵니다.
3. **섞어서 한 장** — 카드를 섞으면 뒷면이 꽃 문양으로 바뀝니다. `한 장 뽑기`로 오늘의 꽃을 뽑습니다.

번호와 꽃 그림은 카드에 고정되어 있어, 섞어도 처음 공개한 짝 그대로 유지됩니다.

## 단축키

`1`~`9` 번호 카드 뒤집기 · `D` 카드뽑기 · `A` 전체공개/덮기 · `S` 섞기 · `Space` 한 장 뽑기 · `R` 처음부터
